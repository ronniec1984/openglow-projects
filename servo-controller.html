ESP32 Neon Servo Controller

Control a servo motor using a glowing web interface.

Overview

This project uses an ESP32 to control a servo motor through a neon‑themed web interface. The ESP32 hosts a local webpage with a glowing slider that updates the servo position in real time.

Parts Needed

  • ESP32 Dev Board
  • SG90 or MG996R Servo
  • 5V Power Source
  • Jumper Wires

void handleRoot() {
  server.send(200, "text/html", htmlPage);
}

void handleSet() {
  if (server.hasArg("value")) {
    int pos = server.arg("value").toInt();
    servo.write(pos);
  }
  server.send(200, "text/plain", "OK");
}

void setup() {
  servo.attach(13);
  WiFi.softAP(ssid, password);
  server.on("/", handleRoot);
  server.on("/set", handleSet);
  server.begin();
}

void loop() {
  server.handleClient();
}
